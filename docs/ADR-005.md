# ADR-005: Unified viewing — HLS gateway with signed segments, no central recording

**Status:** Accepted · **Date:** 2026-09-25

## Context
Module 2 requires authorized live viewing of departmental feeds in one interface
without disturbing existing VMS infrastructure and without centralised storage
of all video. Departmental systems expose RTSP/HLS; browsers need a playable,
permission-checked stream.

## Decision
- Every ingest source is registered as a `stream_source` bound to a Module-1
  camera (department ownership inherited from the registry).
- Watching = `POST /streams/{id}/watch` → creates a `viewer_session`, returns an
  HLS playlist URL scoped to that session. Heartbeats keep it alive; a sweeper
  closes stale sessions.
- The gateway proxies HLS: playlists are fetched from the origin and every
  segment URI is rewritten to `/api/v1/streams/hls/{sid}/{sess}/{token}/seg/{n}`
  with an HMAC-signed, 5-minute TTL token. The origin URL never reaches the
  browser, and authorization is enforced at playlist time.
- Health: a background prober GETs each enabled playlist every 45 s, records
  `stream_health_events` and updates status/latency on the source.
- No video is stored centrally; the platform relays live segments only.

## Rationale
- HLS proxying needs no browser plugins, transcodes nothing, and works with any
  origin that can produce HLS (Sentinel sandbox, ffmpeg test sources, future
  RTSP→HLS relays such as MediaMTX/go2rtc — a drop-in origin swap).
- Session-scoped signed segments satisfy SEC-003 (no publicly exposed camera
  endpoints) without per-segment JWT parsing.
- RTSP support is declared in the model (`protocol` column); playback for RTSP
  origins should be added by inserting a relay, not by changing this contract.

## Consequences
- Per-viewer segment fan-out means the gateway (not the origin) carries viewer
  load; horizontal API scaling applies to viewing too.
- `delete_segments` origins can retire a segment between playlist and fetch;
  the gateway maps that to 404 so players skip instead of failing the wall.
